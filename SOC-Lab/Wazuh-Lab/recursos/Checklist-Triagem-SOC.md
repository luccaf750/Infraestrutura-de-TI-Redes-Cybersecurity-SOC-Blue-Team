# Checklist de Triagem SOC L1

- [ ] Identificar alerta e fonte
- [ ] Registrar data/hora
- [ ] Identificar host
- [ ] Identificar usuário
- [ ] Verificar IP de origem/destino
- [ ] Examinar Event ID e regra
- [ ] Buscar eventos correlacionados
- [ ] Construir sequência temporal
- [ ] Verificar contexto/atividade legítima
- [ ] Mapear MITRE ATT&CK quando aplicável
- [ ] Definir severidade
- [ ] Classificar falso positivo, benigno ou incidente
- [ ] Registrar evidências
- [ ] Definir encerramento ou escalonamento
