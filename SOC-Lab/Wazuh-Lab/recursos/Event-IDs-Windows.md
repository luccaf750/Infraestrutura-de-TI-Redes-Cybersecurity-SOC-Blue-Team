# Windows Security Event IDs — Referência SOC

| Event ID | Descrição |
|---|---|
| 4624 | Logon bem-sucedido |
| 4625 | Falha de logon |
| 4688 | Novo processo criado |
| 4698 | Scheduled Task criada |
| 4720 | Conta de usuário criada |
| 4722 | Conta de usuário habilitada |
| 4726 | Conta de usuário excluída |
| 4732 | Membro adicionado a grupo local de segurança |
| 4733 | Membro removido de grupo local de segurança |
| 7045 | Serviço instalado no sistema |

Use os IDs como ponto de partida; a interpretação depende do contexto e dos demais campos do evento.
