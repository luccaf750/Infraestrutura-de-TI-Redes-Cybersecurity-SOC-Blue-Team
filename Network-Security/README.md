# Network Security

Documentação de conceitos e projetos relacionados à proteção e segmentação de redes, aproveitando experiência com infraestrutura e troubleshooting.

## Tópicos

- TCP/IP
- MikroTik
- VLAN
- Firewall
- VPN
- DHCP
- Routing
- Segmentação de redes
- Controle de acesso
- Segurança de infraestrutura

## Objetivo

Relacionar conhecimentos de infraestrutura com princípios de defesa em profundidade, segmentação, redução de superfície de ataque e controle de comunicação entre redes.
