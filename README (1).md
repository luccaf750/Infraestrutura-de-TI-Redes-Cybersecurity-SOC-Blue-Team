# 🔍 Log Analysis — Windows Security Events

Projeto voltado para análise de eventos de segurança em ambientes Windows, com foco em autenticação, criação de processos e identificação de comportamentos suspeitos.

## Eventos de interesse

- Event ID 4624 — Successful Logon
- Event ID 4625 — Failed Logon
- Event ID 4688 — Process Creation
- Event ID 4720 — User Account Created
- Event ID 1102 — Audit Log Cleared

## Fluxo de análise

```text
Evento → Coleta → Filtragem → Correlação → Investigação → Classificação → Resposta
```

## Competências

`Windows Event Logs` `Log Analysis` `Threat Detection` `Incident Investigation` `SOC`
