# 🐍 Python for Cybersecurity

Projeto voltado ao uso de Python para automação de tarefas relacionadas à análise de logs e segurança da informação.

## Ideias de scripts

- `failed_login_detector.py`
- `log_analyzer.py`
- `ioc_extractor.py`
- `ip_analyzer.py`
- `hash_checker.py`

## Exemplo de objetivo

Analisar arquivos de log, contabilizar falhas de autenticação e identificar endereços IP com comportamento anormal.

## Competências

`Python` `Automation` `Log Analysis` `Cybersecurity`
