# Python for Cybersecurity

Área destinada ao desenvolvimento de scripts Python aplicados à Segurança da Informação.

## Projetos planejados

- Security Log Parser
- Failed Login Analyzer
- IOC Extractor
- IP Analysis
- Automação de tarefas repetitivas

O objetivo é utilizar Python como ferramenta de apoio a atividades de análise, automação e tratamento de dados de segurança.
